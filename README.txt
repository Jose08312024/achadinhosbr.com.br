# Achadinhos BR

Site inicial para a marca Achadinhos BR.

## Como usar
1. Abra `index.html` no navegador.
2. Clique em `⚙️ ADM`.
3. A senha inicial do ADM é: otavioryszaneanny
4. Cadastre nome, preço, categoria, link, foto e descrição.
5. Os produtos aparecem automaticamente na área pública.

## Importante
Esta versão é um protótipo estático: os produtos ficam salvos no `localStorage` do navegador.
Para um site publicado com ADM real, login seguro, banco de dados e produtos sincronizados em vários celulares/computadores, é necessário um backend.
